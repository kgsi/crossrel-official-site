「Claude Code」は、自然言語で指示するだけでコードやWebページを生成できる、AI時代の新しい開発ツールです。本イベントは、デザイナー・PM・ビジネス職などの非エンジニアを対象とした、60分でClaude Codeを動かす体験型ハンズオンです。

参加者はそれぞれの環境にClaude Codeをセットアップし、自然言語のプロンプトからHTMLのWebページを生成するところまでを体験。AIツールを自分のワークフローに取り込むための、実践的な自信を持ち帰っていただきます。
